# Morph Simulator

A native macOS game (Swift + SceneKit): mix the head, body and legs of 100 animals across 10 maps.

- Build: `./build.sh` (needs the Xcode Command Line Tools) → `Morph Simulator.app`
- Download page: `site/` (served by Render as a static site, see `render.yaml`)
- Self-test: `"Morph Simulator.app/Contents/MacOS/MorphSimulator" --autotest`
